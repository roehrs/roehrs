## 👋 Quem eu sou

Sou de Canoas, RS. Passei **sete anos na Dell Technologies** como Technical Support
Engineer, pegando os casos que ninguém tinha conseguido resolver e auditando o
processo pra corrigir na raiz. Foi ali que dado virou ferramenta de decisão pra mim,
não relatório bonito.

Hoje divido o dia entre **ensinar e construir**. No Senac RS sou instrutor técnico e
treino os competidores de Desenvolvimento de Sistemas das Competições Senac. Fora
dali, construo software sob medida pra operação de empresa pequena que travou num
processo manual, e cuido de tráfego pago orientado a métrica.

Meu código quase sempre nasce de um problema que existia antes dele.

```yaml
localizacao:  Canoas, Rio Grande do Sul
formacao:     [Ciência da Computação (La Salle), Ciência de Dados e IA (UniRitter)]
trabalhando:  [Senac RS, EUgência, Família do Personalizado]
construindo:  sistema interno, loja, painel, automação
aprendendo:   Rust, e o que o próximo problema exigir
```
